## 0. Суть

Три контент-трека вместо одного, потому что Stories в одиночку не решают
поставленных целей:

| Трек | Что даёт | Объём |
|---|---|---|
| **Reels** | новую аудиторию из Explore — единственный источник роста | 2–3/нед |
| **Stories** | прогрев и продажи существующим подписчикам | 4/день |
| **Feed** | вечное хранение, поиск, сохранения, лицо профиля | 3/нед |

**Ключевой факт, который переломил план:** Instagram показывает Stories почти
исключительно тем, кто уже подписан — алгоритм ранжирует их по recency и истории
просмотров. Новых людей приносит только Reels. План на одних сторис закрывал бы
3 цели из 4, а «рост подписчиков» не закрывал вообще.

Тебе повезло: Reels-трек у тебя **уже готов** — 8 нейро-роликов в production и
отлаженный пайплайн. Их надо просто подключить к публикации.

### 2.1 Тест на украинском тексте (16.08.2026)

Один и тот же промпт, заголовок «ЇЖОВИК ГРЕБІНЧАСТИЙ» + «Фокус, пам'ять, ясність»:

| Модель | Размер | Результат |
|---|---|---|
| `gemini-2.5-flash-image` | 1K (768×1344) | **1 из 2 с ошибкой** — «ясноть» |
| `gemini-3.1-flash-image` | 2K (1536×2752) | **2 из 2 идеально** |
| `gemini-3-pro-image` | 2K (1536×2752) | **2 из 2 идеально** |

**Вывод: дело в разрешении, а не в модели.** На 2K крупный украинский текст
воспроизводится точно, включая Ї, І, апостроф. Совпадает с твоей находкой
«фікс лого = 2K (image_size)».

**Отсюда — гибрид по назначению:**
- **Модель рисует** крупный заголовок и подзаголовок (живая типографика, вписана
  в сцену) — только при `imageSize: "2K"`
- **PIL накладывает** юридически значимое и мелкое: дисклеймер, промокод,
  плашку «посилання в шапці профілю», логотип. Там нужна 100% точность,
  а мелкий текст модель по-прежнему коверкает

**Грабля с авторизацией (из памяти, подтверждаю):** ADC на машине принадлежит
`info@lisovik.com.ua` с quota-проектом `lisovik-ads-cockpit`, где Vertex
выключен → 403. Обход: брать токен активного логина через
`gcloud auth print-access-token` и передавать в `genai.Client(credentials=...)`.
Токен живёт ~1 час.

## 3. Ограничения

### 3.1 Meta

| Ограничение | Следствие |
|---|---|
| Энтеогены: запрещены buy/sell/trade | Мухомор не постим |
| Обсуждение науки об энтеогенах — разрешено | Форточка есть, но не пользуемся (см. §4.1) |

| Нельзя подразумевать состояние здоровья | «Страждаєш безсонням?» — запрещено |
| Легальность в стране не учитывается | «У нас можно» — не аргумент |

Эскалация: удаление → снижение охватов → блокировки на 1/3/7/30 дней → отключение.

**Страховка — существующий Telegram-канал, а не резервный Instagram.** Бан
каскадит на весь Business Manager, поэтому запасной IG под тем же BM умер бы
вместе с основным, а под отдельным — это пустой дубль ради дубля. Решение
Ярика (16.08): резервный аккаунт не заводим, аудиторию при бане уводим в
Telegram, который уже есть.

### 3.2 API

Через `media_type=STORIES` — только голое фото или видео. Не работают: ссылка-стикер,
опросы, викторины, музыка, GIF, countdown. У платных сервисов ровно то же.

Reels публикуются тем же API (`media_type=REELS`) — трек не требует отдельной механики.

## 4. Контент-стратегия

### 4.1 Позиционирование

Аккаунт = «ліс, ритуал і турбота про себе». Витрина строится на непсихоактивной
части ассортимента: їжовик, кордицепс, рейші, чага, шиітаке, майтаке, трутовик,
ашваганда, грибна кава, мармелад, шоколад, курси, спіруліна, хлорела.

**Мухомор в Instagram не появляется вообще** — ни в тексте, ни в кадре, ни в
рубрике «Міфи». Формально Meta разрешает научное обсуждение энтеогенов, но
пользоваться этой форточкой не будем: разница между «обсуждением» и «продвижением»
решается классификатором, а цена ошибки — весь аккаунт.

**Отдельный риск: мухомор может вылезти сам.** Красная шляпка в белый горошек —
дефолтный образ при промпте «лісовий гриб». Меры:
- негатив-констрейнт в каждом промпте: `no red-and-white spotted mushrooms,
  no Amanita muscaria`
- обязательный пункт в Telegram-ревью: «немає впізнаваного мухомора в кадрі»

**Остаточный риск, который принимаем осознанно:** bio-ссылка ведёт на сайт, где
мухомор продаётся открыто. Полное решение — отдельный лендинг для IG-трафика без
мухомора. Решай: делаем лендинг или принимаем риск.

## 5. Архитектура

Главная переделка v2: состояние живёт **в облаке**, а не в локальных папках.
Рецензент справедливо заметил — GitHub Actions получает чистый checkout и диска
твоего компа не видит.

```
   ЛОКАЛЬНО (твой комп)              ОБЛАКО (работает без тебя)
   ─────────────────────             ──────────────────────────
   generate.py                       Cloud Run: review_bot
     Gemini 3.1-flash-image 2K         Telegram webhook
     + заголовок в сцене               [В ефір] → manifest
     + logo_2K референс                        ↓
     + негатив мухомора              GCS: bucket
        ↓                              media/*.jpg
   compose.py (PIL)                     manifest.json
     дисклеймер, промокод,
     плашка, логотип
        ↓                                      ↓
   lint.py                            GitHub Actions cron (*/15)
     стоп-слова + глифы                 читает manifest
        ↓                               берёт слот по времени
   upload → GCS + manifest              ↓
                                      Graph API
                                        create container
                                        poll FINISHED
                                        media_publish
                                        ↓
                                      insights.py → отчёт в Telegram
```

**Манифест** (`gs://bucket/manifest.json`) — единственный источник правды:

```json
{
  "items": [
    {
      "id": "2026-08-20-story-gryb-dnya",
      "type": "STORIES",
      "media_url": "https://storage.googleapis.com/.../gryb.jpg",
      "slot_start": "2026-08-20T09:30:00+03:00",
      "slot_end":   "2026-08-20T11:00:00+03:00",
      "status": "approved",
      "rubric": "gryb-dnya",
      "published_at": null,
      "ig_media_id": null
    }
  ]
}
```

### 5.1 Технические решения

| Задача | Решение | Почему так |
|---|---|---|
| Секреты | **GCP Secret Manager** | локальный `.env` и GitHub Secrets разъедутся; токен обновляется в одном месте |
| Ревью-бот | **Cloud Run + webhook** | long polling на твоём компе = ревью только при включённом компе |
| Cron не умрёт | keepalive-коммит раз в месяц | GitHub отключает scheduled workflow после 60 дней без активности |
| Heartbeat | внешний монитор | если cron умер, алерт не придёт из того же cron |
| Часовой пояс | cron в UTC, слоты в Europe/Kyiv | EET/EEST переводится дважды в год — считаем в коде, не в cron |
| Бакет | uniform access + lifecycle 90 дней | публичный бессрочно = картинка живёт после удаления сторис |
| Репозиторий | **приватный** | pwn request через форк — известный вектор утечки секретов |

### 5.2 Windows-грабли (учтены заранее)

- Путь проекта содержит кириллицу и пробелы → все `subprocess` без `shell=True`,
  пути через `pathlib` и списком аргументов
- `ffmpeg` filtergraph ломается на `C:\` → пути приводим к forward-slash
- Консоль не UTF-8 → `PYTHONUTF8=1` в обёртке, логи в файл
- `Set-Content -Encoding UTF8` пишет BOM и ломает `json.load` → использовать
  `[System.IO.File]::WriteAllText` с `UTF8Encoding($false)` *(из твоей памяти)*
- `rembg` требует VC++ Redistributable и `rembg[cpu]`
- Шрифт: проверить наличие глифов `ї є ґ і ' ` до старта — многие «кириллические»
  шрифты их не содержат

## 9. Риски

| Риск | Уровень | Что делаем |
|---|---|---|
| Бан за нишу | **HIGH→MEDIUM** | мухомор не постим; линтер; негатив-констрейнт; дисклеймеры |
| Мухомор на генерации | средний | негатив в промпте + пункт ревью |
| Каскадный бан BM | средний | резервный аккаунт под отдельным BM |
| Bio-ссылка на сайт с мухомором | **остаточный** | отдельный лендинг либо принять осознанно |
| Юрстатус мухомора | **неизвестен** | юрпроверка до Этапа 1 |
| Cron умер после 60 дней | высокий | keepalive + внешний heartbeat |
| Токен протух | средняя | Secret Manager + обновление на 45-й день + алерт |
| Ошибка в украинском | средняя | генерация только в 2K + PIL для мелкого + вычитка |
| Логотип «ЛІСОВНК» | высокая | logo_2K вторым референсом *(проверено тобой)* |
| Депрекация модели | средняя | модель в конфиге; Imagen уже умер, 3.1-flash уже пропадала и вернулась |
| Свет/тревоги | средний | окна ±60–90 мин |

**Recovery playbook** (чего не было в v1): при бане — апелляция в первые 24 часа
через встроенную форму; аудитория уводится в Telegram-канал (готовим заранее,
не после бана); резервный аккаунт под отдельным BM; весь контент хранится в GCS,
не только в Instagram.

## 12. Что не делаем

- **IG Shop** — запрещён для supplements, включая безобидную ашваганду
- **Реклама через Ads Manager** — до отладки органики; отклонённые объявления
  бьют по репутации аккаунта
- **Мухомор в IG** — ни текстом, ни картинкой, ни в «Міфах»

- **Полный автомат с первого дня** — минимум 2 недели ручного ревью
- **Массовые операции без спроса** — правило из твоей памяти: если проблема на
  N объектах, чиним ровно эти N
